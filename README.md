# Flypaper

Учебный сайт по дисциплине «Вёрстка» — авиация, споттинг, лабораторные.
Чистые HTML, CSS и JS, без фреймворков, библиотек и сборки: файлы из `public/`
открываются браузером как есть.

## Структура

├── gallery/                    галерея споттинга (просмотр на <dialog>)

### Как устроены стили и скрипты

- Каждая обычная страница подключает `assets/css/main.css` и стили своей страницы из
  `assets/css/pages/`. Порядок файлов в `main.css` важен: токены → база → утилиты → компоненты.
- Растр поверх фото — утилита `.halftone` (`base/utilities.css`): добавьте класс блоку с картинкой,
  сила точек задаётся переменной `--halftone-opacity` на том же блоке.
- Скрипты — ES-модули (`<script type="module">`): `assets/js/main.js` на каждой странице
  и, если нужно, точка входа страницы из `assets/js/pages/`. Пути к картинкам и API модули
  считают от своего расположения (`import.meta.url`), поэтому работают с любой страницы.
- Шапка и подвал повторяются в каждой странице: без сборки HTML не подключить из одного файла.
  Меняете меню — меняйте его во всех `index.html` и статьях.

## Запуск

Нужен Python 3.10+. Один раз установить сервер в виртуальное окружение:

```
python -m venv .venv
.venv\Scripts\activate             # Windows; на Linux/macOS: source .venv/bin/activate
python -m pip install -e "./server[dev]"
```

Запуск (из любой папки):

```
python -m flypaper                 # http://127.0.0.1:8000
```

Открыть для других устройств в сети (адрес и порт задаются переменными окружения):

```
# Linux / macOS
HOST=0.0.0.0 PORT=8000 python -m flypaper
# Windows PowerShell
$env:HOST="0.0.0.0"; $env:PORT="8000"; python -m flypaper
```

Папку сайта можно указать явно: `FLYPAPER_PUBLIC_DIR=/путь/к/public`.
Наружу не отдаются скрытые файлы, списки файлов в папках и всё, что лежит вне `public/`.

Без сервера табло и обои переходят в демо-режим. Скрипты подключены как ES-модули,
поэтому страницы нужно открывать через HTTP, а не двойным щелчком по файлу.
Встроенный `python -m http.server` на Windows может отдавать `.js` как `text/plain`,
и браузер такие модули не загрузит; сервер проекта задаёт типы файлов сам.

## Что делает сервер

- `GET /api/board` — табло Пулково для главной: вылет и прилёт. Отдельный поток раз
  в минуту берёт расписание из FlightRadar24. До первого удачного ответа — 503,
  страница тогда показывает демо-расписание. Время отдаётся в UTC, перевод статусов
  и московское время — на странице.
- `GET /api/aircraft` — `{"aircraft": {...}}`, ближайший к Петербургу самолёт для обоев;
  фоновый поток опрашивает FlightRadar24 раз в 10 секунд.
- `GET /api/guestbook` — `{"entries": [...]}`, записи гостевой книги, новые первыми.
- `POST /api/guestbook` — новая запись: JSON `{"name", "airport", "airline", "text"}`.
  Сервер проверяет поля по тем же правилам, что и форма, ставит дату и дописывает
  строку в `server/data/guestbook.txt`. Ответ — 201 или 400 с текстом ошибки.
  Другой файл можно указать переменной `FLYPAPER_GUESTBOOK_FILE`.

Код аэропорта, координаты, радиус и интервалы опроса — в `server/src/flypaper/config.py`.

## Хвосты авиакомпаний

Готовая библиотека по двухсимвольному коду IATA, ничего не скачивается:

- `assets/img/tails/XX.png` — плоский хвост 600×600 (гостевая, табло на главной);
- `assets/img/liveries/XX.png` — тот же хвост на шаблоне для обоев.

Если кода в библиотеке нет, показывается запасной хвост: `assets/img/tails/default.svg`
на сайте и `assets/img/liveries/empty.png` в обоях.

## Как добавить контент

- Фото споттинга: положить файл в `public/assets/img/gallery/` и добавить блок `<figure>`
  в `public/gallery/index.html`.
- Новая лабораторная: добавить `<figure class="lab-work">` в `public/labs/index.html`,
  её стили — отдельным файлом в `public/assets/css/labs/` (и подключить на странице),
  картинки — в `public/assets/img/labs/`.
- Новая статья: скопировать `public/articles/a340-600.html`, картинки — в `assets/img/photos/`,
  карточку — в `public/articles/index.html`.
